      03Back up your radio + create ZIPRecommended: save a verified recovery folder and ZIP before updating.RecommendedShow detailsHide details

      Choose a folder outside the radio drives. Keep it for recovery.

      Includes the firmware currently on your radio (stock or KS) and all accessible SD files, except operating-system metadata. Keep space for both copies—about twice the backup size. This process can take 10–20 minutes, depending on how much data is on your radio’s SD card.

      A dated ZIP is created automatically and checked when you choose to back up. Untouched images, sounds and logs are read from the radio during backup, without repeated content scans.

      04Install updateInstall and verify the SD files, then automatically copy the firmware.Show detailsHide details

      The installer replaces the matching program files and clears their old program caches. Your existing ExpressLRS tool is kept. If a write fails, it attempts to restore the previous SD files from your backup.

      Once the SD files pass verification, the installer automatically copies the verified UF2 to EDGETX_UF2. Keep this tab open and the USB cable connected until the radio finishes writing.

      Available after a verified backup or confirmation to skip it.

      The original firmware stays in your backup folder and ZIP. Firmware copying cannot be cancelled once it begins.

      If your browser cannot copy the UF2

      You can download the same verified UF2 and copy it with Finder or File Explorer. After Writing complete, follow the full radio restart in step 05, then run the final check. A browser error can occur after writing has started: check the readback before trying another copy.

      05Restart & verify installationCopying the file is not the final check.Show detailsHide details

      Keep this installer tab open. It will wait while the radio is off.

      1. Wait until the radio says Writing complete.
      2. Eject the radio drives on your computer, then unplug the USB cable.
      3. Turn the radio off.
      4. With USB still unplugged, start the radio in bootloader mode again.
      5. Plug USB back in and wait for both drives to appear.
      6. Reselect both drives using the buttons below, confirm below, then verify.

      Checks the new firmware and the release files installed in step 04. Personal settings, logs and other unrelated files are not compared with the old backup.

      Update complete — all checks passed

      Eject both drives through your computer, unplug USB and restart the radio normally. If a model needs its home screen created, tap Setup Homescreen and choose its dashboard options. Check telemetry and controls on the bench before flight.

      Recovery & reconnect

      If the browser closes or a drive disconnects, reconnect the same radio, load the release, select both drives and your existing backup folder. Before firmware copying, use Restore SD files to recover the previous program files. After a firmware attempt, wait for writing to finish, unplug USB, turn the radio off, enter bootloader mode again, reconnect USB and reselect both drives. Confirm that restart and run the final check; the installer will not automatically retry the flash.

      SD-only restore is blocked after firmware copying. If you need to roll back, use your original backup and the package instructions to restore firmware and SD files together.
